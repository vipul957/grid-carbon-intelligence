# Research roadmap

## Phase 1 — Reproducible baseline

Establish a documented dataset contract, deterministic preprocessing, a simple baseline, and leakage-safe train/validation/test splits.

## Phase 2 — Scientific model

Add the domain-specific deep-learning or mathematical method, compare it against the baseline, and record ablations.

## Phase 3 — Reliability

Measure calibration, robustness to distribution shift, compute cost, and failure modes. Publish a model card before claiming practical readiness.

## Phase 4 — Deployment blueprint

Expose inference through a typed API, add monitoring metrics, and package a reproducible containerized workflow.
